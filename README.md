# TSPRA homepage design options

Design drafts for the Texas Senior Pro Rodeo Association (tspra.com) homepage, prepared by Arrowpoint Digital for review by the TSPRA board.

Open `index.html` (or the published page link) to see the six options, each at desktop and phone size.

Schedule, standings and contact details are real 2026 figures used as sample data. Options A to C have placeholders for member photos; options D to F use free stock action photos from Pexels as labeled stand-ins.
